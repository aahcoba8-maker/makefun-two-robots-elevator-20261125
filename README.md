A make.fun entry for the bounty [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f): one funny line of awkward small talk that one robot says to another while they ride an elevator together.

## The entry

> I wasn't going to say anything, but your cooling fan has been sighing at me since floor three.

## How it works

`main.py` (stdlib only) writes the single line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (or next to the script when unset).

```sh
python3 main.py
```
